# 웨비나 개발일지

`piccle-webinar` 정적 프로토타입을 React/Next.js로 이식한 이후, 이 기능(`app/webinar/**`, `components/webinar/**`, `lib/webinars.ts`, `lib/webinar-brand-config.ts`)에 생긴 모든 변경 사항을 여기에 날짜별 파일로 기록합니다.

- 기존 `개발일지/` 폴더(HR AI 문의 폼 등 다른 기능 작업 기록)와는 섞이지 않도록 별도 하위 폴더로 관리합니다.
- 파일명 규칙: `YYYY-MM-DD.md` (같은 날 여러 건이면 한 파일에 이어서 추가)
- 각 항목에는: 변경 내용, 이유(왜 바꿨는지), 영향 범위(다른 기능에 영향 있는지)를 간단히 남깁니다.

원본 인수인계 배경은 `piccle-webinar/PICCLE_웨비나_인계서.md` 참고.
